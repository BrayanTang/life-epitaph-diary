# 人生剧情「丰富」与广场献花

## 产品意图

为生活并不「精彩」的人，把碎片日子写成可被温柔夸大的故事——像唐吉诃德把风车当成巨人。章节不是冷冰冰的周报，而是可以点开阅读、再亲手添一笔的叙事。

## 交互

1. **墓碑广场**：每张匿名卡片有「献一束花」；点一下花数 +1（无评论）。
2. **人生剧情**：列表只作入口；点开进入章节详情，读完整故事。
3. **丰富这段故事**：详情页底部输入框，自动保存用户补充的笔迹（本地 SQLite），用来把平凡写成冒险。
4. **自由日志（我的）**：不绑今日提问；输入任意一段 →「写入日志」→ 私密时间线（仅本地）。
5. **广场分享勾选**：在「我的」勾选要公开的字段（墓名/墓志铭/状态/皮肤/近章标题/一句心情），预览后「发布到广场」；章节正文与完整日志永不公开。

## 示例章节（种子）

- 《序章 · 一块安静的石头》：钥匙 / 树 / 面包 → 盔甲暗格 / 瞭望塔 / 干粮  
- 《唐吉诃德大战风车》：地铁通勤写成冲向金属风车的小小开战
