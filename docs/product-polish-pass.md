# 产品打磨说明（本轮）

## 目标
让 M1 壳子更像「安静的墓碑日记」，而不是功能清单。

## 已优化
- **墓碑主页**：更大墓碑视觉、立碑引导、皮肤选择、事后可改墓碑、今日提问入口、近期剧情可点进详情、日志/广场捷径、献花合计
- **今日提问**：自动保存说明；本周碎片卡片化；引导去剧情页织故事
- **人生剧情**：「织成本周剧情」用本周短答生成唐吉诃德式章节；打开故事 + 一键分享；详情可丰富（预览合入正文下方）
- **广场**：全部 / 我的；我的页看献花数；一键分享日志或剧情；空态文案
- **我的**：自由日志 + 隐私开关（是否出现在广场）
- **Mock 周章**：Shared `QuixoteChapterComposer`，客户端与 API 共用
- **题库**：补充风车/钥匙/冒险/夜营向轻提问
- **Tab**：主页 / 今日 / 剧情 / 广场 / 我的

## 仍未做（有意）
- 真实国内大模型接入
- 商店打包、推送、建墓皮肤资源包
