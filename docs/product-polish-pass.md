# 产品打磨说明（本轮）

## 目标
让 M1 壳子更像「安静的墓碑日记」，而不是功能清单。

## 已优化
- **墓碑主页**：更大墓碑视觉、立碑引导（墓名/墓志铭/状态）、今日提问入口、近期剧情可点进详情、日志/广场捷径
- **今日提问**：更清楚的自动保存说明；本周碎片卡片化
- **人生剧情**：打开故事 + 一键分享；详情可丰富、可分享
- **广场**：全部 / 我的；我的页看献花数；一键分享日志或剧情
- **Mock 周章**：短答改写成唐吉诃德式隐喻叙事（仍无真实 API Key）
- **题库**：补充风车/钥匙/冒险向轻提问

## 仍未做（有意）
- 真实国内大模型接入
- 商店打包、推送、建墓皮肤资源包
